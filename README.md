# name of your project

Ping

## how to use it

Type in any key from the number pad or row to play
a different version of the hit effect from
recent releases of Pong

## how it works

A spinning square turns in 3d via the linear infinite property
The different sounds are created by changing the pitch of different presets
thje "type 0-9" and 0-9 screens are made with canvas

npm install
node build.mjs
